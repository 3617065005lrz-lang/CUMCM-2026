重点：三种方案
| 方案        | 计划购电量的产生方式                         | 储能处理                        | 作用              |
| --------- | ---------------------------------- | --------------------------- | --------------- |
| 规则基线      | 1月15日前使用预测净负荷；有残差后取各时段情景净负荷的80%分位数 | 按相同的实际调度规则充放电               | 最简单、可解释的基准      |
| 确定性线性规划   | 仅根据负载和光伏点预测进行单情景优化                 | 在线性规划中考虑储能，实际运行仍按统一规则执行     | 衡量“引入优化”的价值     |
| 两阶段随机线性规划 | 同时考虑50个负载—光伏联合情景，计划购电量在所有情景中共享     | 各情景拥有自己的充电、放电、SOC、弃光和应急购电变量 | 衡量“考虑预测不确定性”的价值 |

数据处理口径
将附件2两张宽表转换为“日期 × 连续时段”的长表。
每天固定144个连续10分钟时段，编号为1～144。
原始负载和光伏单位为kW；进入能量平衡前乘以 \(1/6\)，转换为kWh。
原始真实数据全部保留，不进行平滑，不随意删除极端值。
当前无缺失、重复和负值，因此主要进行一致性校验与异常标记。
光伏情景值因叠加残差出现负数时，按照解读截断为0。
附件1只作为电价来源和冷启动先验，不进入有效残差库。
预测评价口径

负载预测输出：

MAE；
RMSE；
MAPE；
分时段误差和逐日误差；
真实值、预测值与残差明细。

光伏预测输出：

MAE；
RMSE；
归一化MAE；
白天有效发电时段的MAPE；
全时段MAPE不作为主要指标，因为夜间真实值为0，会导致比例误差失真。



# 问题二代码说明（第一版）

## 1. 文件用途

`problem2_stochastic_programming_第一版.py`用于完成问题二的全年数据处理、滚动预测、联合残差情景生成、两阶段随机线性规划、实际运行模拟和三方案比较。

程序按照每天144个10分钟时段运行，并将储能状态连续传递到下一天。1月份作为预测冷启动、残差积累和储能状态预热阶段，正式结果统计范围为2025年2月1日至12月31日。

## 2. 运行环境

- Python 3.11及以上
- pandas
- numpy
- scipy
- matplotlib
- openpyxl

安装依赖：

```bash
py -3.11 -m pip install pandas numpy scipy matplotlib openpyxl
```

建议将以下文件放在同一文件夹中：

```text
附件1.xlsx
附件2.xlsx
problem2_stochastic_programming_第一版.py
```

## 3. 输入数据

### 3.1 附件1

附件1提供一天144个10分钟时段的：

- 电价；
- 小区负载先验；
- 光伏发电先验。

其中电价曲线重复映射到2025年的每一天。负载和光伏曲线只用于年初冷启动，不作为真实历史日期加入联合残差池。

### 3.2 附件2

附件2包含两个工作表：

- 小区负载；
- 光伏发电实际功率。

两张表均为365天 × 144个时段，覆盖2025年全年。输入功率单位为kW，每10分钟电量按照“功率 × 1/6小时”换算为kWh。

## 4. 数据处理

程序首先完成：

- 日期和144个时段对齐；
- 缺失值、重复值、负值和非法时间检查；
- 每日记录数量和全年日期连续性检查；
- 宽表转换成长表；
- 负载功率和光伏功率转换为区间电量；
- 实际净需求电量计算；
- 预处理前后对比；
- 异常记录和数据质量报告保存。

实际净需求电量定义为：

```text
实际净需求电量 = 小区耗电量 - 光伏发电量
```

它表示扣除光伏发电后仍需要由计划购电、储能放电和紧急购电共同承担的电量，不等于实际购电量。

## 5. 滚动预测

每天0:00只使用决策日前已经获得的数据生成当天预测，禁止使用当天未来实际值。

### 5.1 负载预测

- 1月1日至1月7日：使用附件1负载先验；
- 1月8日至1月14日：附件2前7日实际负载与附件1先验等权平均；
- 1月15日起：附件2前7日和前14日实际负载等权平均。

### 5.2 光伏预测

- 1月1日至1月3日：缺失历史日期使用附件1光伏先验补足；
- 1月4日起：使用前三日实际光伏功率的平均值；
- 预测夜间时段设置为0；
- 预测光伏功率不得为负。

每个时段同时保存预测值、实际值、预测残差和预测来源。

## 6. 联合残差情景

- 1月1日至1月14日为冷启动期，残差不进入抽样池；
- 1月15日形成第一条有效联合残差；
- 1月15日及以前使用确定性情景；
- 1月16日起，从已有有效残差中有放回抽取情景；
- 默认抽取50个完整日的负载—光伏联合残差；
- 有效记录超过60日后，只保留最近60日；
- 使用固定随机种子；
- 保存每天抽中的残差日期。

抽取整日联合残差可以保留负载、光伏和日内时段之间的相关结构，避免分别打乱后产生不合理情景。

## 7. 两阶段随机线性规划

### 7.1 第一阶段

在当天实际负载和光伏出现前，统一决定144个时段的计划购电量。

### 7.2 第二阶段

针对每个随机情景，分别决定：

- 储能充电量；
- 储能放电量；
- 时段末储电量；
- 弃光或未利用电量；
- 紧急购电量。

### 7.3 目标函数

模型最小化：

```text
计划购电费用 + 期望紧急购电费用 - 日末储电价值
```

紧急购电单价为对应时段电价的5倍。日末储电价值用于避免模型为了降低当天费用而不合理地耗尽储能。

### 7.4 储能参数

| 参数        | 数值          |
| --------- | -----------:|
| 初始储电量     | 6000 kWh    |
| 最低储电量     | 1200 kWh    |
| 最高储电量     | 10800 kWh   |
| 最大充放电功率   | 5000 kW     |
| 单时段最大充放电量 | 833.333 kWh |
| 充电效率      | 0.90        |
| 放电效率      | 0.90        |
| 紧急购电价格倍数  | 5倍          |
| 默认情景数     | 50          |
| 默认残差窗口    | 60日         |

问题二不强制每天日末储电量回到6000 kWh，而是将当天实际日末SOC作为下一天日初SOC。

## 8. 三种比较方案

程序同时运行：

1. 规则基线：残差池为空时使用预测净需求；残差池可用后使用情景净需求的80%分位数；
2. 确定性线性规划：只使用单一预测情景；
3. 两阶段随机线性规划：使用联合残差随机情景。

三个方案使用相同的实际负载和实际光伏，但分别维护自己的SOC状态。

## 9. 实际运行模拟

每个10分钟时段计算：

```text
实际偏差 = 计划购电量 + 实际光伏电量 - 实际负载电量
```

- 实际偏差大于0：优先为储能充电，剩余部分记为弃光或未利用电量；
- 实际偏差小于0：优先由储能放电，剩余缺口通过紧急购电补足；
- 实际偏差等于0：不执行充放电和紧急购电；
- 每个时段结束后更新SOC；
- 当天日末SOC传递至下一天。
