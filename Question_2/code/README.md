重点：三种方案
| 方案        | 计划购电量的产生方式                         | 储能处理                        | 作用              |
| --------- | ---------------------------------- | --------------------------- | --------------- |
| 规则基线      | 1月15日前使用预测净负荷；有残差后取各时段情景净负荷的80%分位数 | 按相同的实际调度规则充放电               | 最简单、可解释的基准      |
| 确定性线性规划   | 仅根据负载和光伏点预测进行单情景优化                 | 在线性规划中考虑储能，实际运行仍按统一规则执行     | 衡量“引入优化”的价值     |
| 两阶段随机线性规划 | 同时考虑50个负载—光伏联合情景，计划购电量在所有情景中共享     | 各情景拥有自己的充电、放电、SOC、弃光和应急购电变量 | 衡量“考虑预测不确定性”的价值 |

数据处理口径
将附件2两张宽表转换为“日期 × 连续时段”的长表。
每天固定144个连续10分钟时段，编号为1～144。
原始负载和光伏单位为kW；进入能量平衡前乘以 \(1/6\)，转换为kWh。
原始真实数据全部保留，不进行平滑，不随意删除极端值。
当前无缺失、重复和负值，因此主要进行一致性校验与异常标记。
光伏情景值因叠加残差出现负数时，按照解读截断为0。
附件1只作为电价来源和冷启动先验，不进入有效残差库。
预测评价口径

负载预测输出：

MAE；
RMSE；
MAPE；
分时段误差和逐日误差；
真实值、预测值与残差明细。

光伏预测输出：

MAE；
RMSE；
归一化MAE；
白天有效发电时段的MAPE；
全时段MAPE不作为主要指标，因为夜间真实值为0，会导致比例误差失真。

预测评价分为：

1月1日至14日：冷启动预测，仅记录，不计入正式模型评价；
1月15日至31日：有效预测与残差积累期；
2月1日至12月31日：正式评价期。
