# 问题四：波动电价下的微网随机滚动购电模型

## 1. 问题概述

问题四在问题二和问题三的基础上引入实时波动电价。附件 4 给出 2025 年 1 月 1 日至 12 月 31 日每个 10 分钟时段的实际电价。问题四分别在波动电价环境下重新计算问题二和问题三，并形成：

- `result4-2.xlsx`：波动电价下对应问题二的结果；
- `result4-3.xlsx`：波动电价下对应问题三的结果。

问题四保持问题二、问题三已经确定的负载预测、光伏预测、联合残差情景、两阶段随机线性规划、CVaR 风险控制、储能物理约束、真实逐时段回放和 SOC 跨日连续机制。新增的不确定因素为未来电价。

问题四的统一方法链为：

\[
\boxed{
\text{负载预测}
+
\text{光伏预测}
+
\text{电价预测}
}
\]

\[
\Downarrow
\]

\[
\boxed{
\text{负载—光伏—电价联合残差情景}
}
\]

\[
\Downarrow
\]

\[
\boxed{
\text{两阶段随机线性规划}
+
\text{CVaR 尾部风险控制}
}
\]

\[
\Downarrow
\]

\[
\boxed{
\text{真实负载、真实光伏、真实电价逐时段回放}
}
\]

其中，问题四对应问题三的模型进一步在 \(0{:}00\)、\(6{:}00\)、\(12{:}00\)、\(18{:}00\) 四个信息时点进行滚动更新。

## 2. 两个子问题

### 2.1 问题 4-2

问题 4-2 是问题二在波动电价环境下的扩展。

每天 \(0{:}00\)：

1. 预测当天负载；
2. 预测当天光伏功率；
3. 预测当天 144 个时段的交易电价；
4. 构造负载—光伏—电价联合随机情景；
5. 一次性确定全天计划购电量；
6. 使用真实负载、真实光伏和真实电价逐时段回放；
7. 当供电不足且储能无法继续补充时，按交易时刻真实电价的 5 倍紧急购电。

输出文件为：

\[
\boxed{\texttt{result4-2.xlsx}}
\]

### 2.2 问题 4-3

问题 4-3 是问题三在波动电价环境下的扩展。

每天在：

\[
0{:}00,\quad6{:}00,\quad12{:}00,\quad18{:}00
\]

四个时刻进行信息更新。

每次更新同时使用：

- 当前可获得的官方光伏预报；
- 当前可获得的历史及当日已实现电价；
- 当前实际 SOC；
- 当前时刻之前已完成的历史负载、光伏和价格残差。

\(0{:}00\) 制定原始计划购电量，\(6{:}00\)、\(12{:}00\)、\(18{:}00\) 只调整尚未执行的未来购电量。

输出文件为：

\[
\boxed{\texttt{result4-3.xlsx}}
\]

## 3. 信息边界

附件 4 中的全年电价属于事后真实数据。模型在某一决策时刻只能使用该时刻之前已经实现的真实电价。

每天 \(0{:}00\) 不读取当天尚未发生的真实电价。

在 \(6{:}00\) 决策时，只允许使用当天 \(0{:}00\)—\(6{:}00\) 已实现电价。

在 \(12{:}00\) 决策时，只允许使用当天 \(0{:}00\)—\(12{:}00\) 已实现电价。

在 \(18{:}00\) 决策时，只允许使用当天 \(0{:}00\)—\(18{:}00\) 已实现电价。

未来实际价格只用于：

1. 对应时段实际结算；
2. 事后策略回放；
3. 后续日期的价格预测训练与残差池更新；
4. 模型评价。

该规则与问题二、问题三中负载和光伏的因果信息边界保持一致。

## 7. 因果负载预测

问题 4-2 和问题 4-3 均沿用问题二的负载预测。

对第 \(d\) 天第 \(t\) 个时段：

\[
\boxed{
\widehat L_{d,t}=L_{d-7,t}.
}
\]

即使用上周同日同刻实际负载作为预测。

前 7 天没有上周同期数据时，使用附件 1 中的负载曲线作为冷启动先验。

当天尚未发生的真实负载不进入当天的预测与优化。

## 8. 问题 4-2 光伏预测

问题 4-2 沿用问题二的统计光伏预测。

\[
\boxed{
\widehat P^{pv}_{d,t}
=
\sum_{j=1}^{7}w_jP^{pv}_{d-j,t}
}
\]

其中：

\[
w_j
=
\frac{
\exp\left(-\frac{j-1}{3}\right)
}{
\sum_{r=1}^{7}
\exp\left(-\frac{r-1}{3}\right)
}.
\]

历史越近，权重越大。

年初历史不足 7 天时，使用附件 1 光伏预测曲线补足冷启动位置。

## 9. 问题 4-3 光伏预测

问题 4-3 沿用问题三的组合光伏预测。

附件 3 每天在：

\[
0{:}00,\quad6{:}00,\quad12{:}00,\quad18{:}00
\]

发布未来 24 小时整点光伏预测。

整点预报通过 PCHIP 转换为 10 分钟分辨率：

\[
\widehat P^{off}_{d,t,h}.
\]

统计预测为：

\[
\widehat P^{stat}_{d,t}.
\]

组合预测定义为：

\[
\boxed{
\widehat P^{pv}_{d,t,h}
=
\beta_{d,h}\widehat P^{off}_{d,t,h}
+
(1-\beta_{d,h})\widehat P^{stat}_{d,t}.
}
\]

其中：

\[
0\le\beta_{d,h}\le1.
\]

\(\beta_{d,h}\) 只利用当前日期之前已经完成的历史日滚动估计。

四个发布时间分别估计权重，不预设单调关系。

# 10. 电价预测模型

## 10.1 日内同刻历史基线

附件 4 的实际价格记为：

\[
p_{d,t}.
\]

首先利用最近 7 个已完成历史日构造同刻价格基线：

\[
\boxed{
\widehat p^{base}_{d,t}
=
\sum_{j=1}^{7}
\omega_jp_{d-j,t}
}
\]

其中：

\[
\omega_j
=
\frac{
\exp\left(-\frac{j-1}{3}\right)
}{
\sum_{r=1}^{7}
\exp\left(-\frac{r-1}{3}\right)
}.
\]

该结构刻画日内时段结构、近期价格水平及短期持续性。

历史不足 7 天时，使用已经完成的历史日与附件 1 电价曲线共同形成冷启动基线。

## 10.2 \(0{:}00\) 电价预测

每天 \(0{:}00\) 尚未观察到当天实际价格，全天价格预测取：

\[
\boxed{
\widehat p_{d,t\mid0}
=
\max\left(0,\widehat p^{base}_{d,t}\right).
}
\]

该预测用于问题 4-2 全天计划以及问题 4-3 的 \(0{:}00\) 原始计划。

## 10.3 日内价格状态修正

问题 4-3 在 \(6{:}00\)、\(12{:}00\)、\(18{:}00\) 时已经观察到当天部分实际价格。

令 \(\tau_h\) 表示当前决策节点最后一个已完成时段：

\[
\tau_h\in\{36,72,108\}.
\]

取最近 1 小时，即 6 个已完成时段的平均价格残差：

\[
\boxed{
b_{d,h}
=
\frac{1}{6}
\sum_{r=\tau_h-5}^{\tau_h}
\left(
p_{d,r}
-
\widehat p^{base}_{d,r}
\right).
}
\]

\(b_{d,h}\) 表示当天已实现价格相对于历史同刻基线的偏离。

## 10.4 价格状态传递系数

对每个决策时刻 \(h\) 和未来预测步长 \(\ell\)，利用最近 60 个已完成历史日估计：

\[
\theta_{d,h,\ell}
=
\arg\min_{\theta}
\sum_{k\in\mathcal W_{d}}
\left[
r^p_{k,\tau_h+\ell}
-
\theta b_{k,h}
\right]^2,
\]

其中：

\[
r^p_{k,t}
=
p_{k,t}
-
\widehat p^{base}_{k,t},
\]

\[
\mathcal W_d
=
\{k<d\}
\]

且最多保留最近 60 个已完成历史日。

取：

\[
\boxed{
\theta_{d,h,\ell}\in[-1,1].
}
\]

无有效历史样本时：

\[
\theta_{d,h,\ell}=0.
\]

## 10.5 日内更新后的价格预测

对 \(t>\tau_h\)：

\[
\boxed{
\widehat p_{d,t\mid h}
=
\max
\left[
0,
\widehat p^{base}_{d,t}
+
\theta_{d,h,t-\tau_h}
b_{d,h}
\right].
}
\]

因此：

- \(0{:}00\) 仅使用历史同刻价格；
- \(6{:}00\) 使用截至 6 点已经实现的价格修正剩余预测；
- \(12{:}00\) 使用截至 12 点的实际价格重新修正；
- \(18{:}00\) 使用截至 18 点的实际价格重新修正。

当天未来真实价格不进入当前优化。

# 11. 价格预测的滚动回测

历史价格残差由因果滚动预测产生。

对已经完成的历史日 \(k\)：

1. 使用 \(k\) 日之前的数据建立价格基线；
2. 在 \(0{:}00\)、\(6{:}00\)、\(12{:}00\)、\(18{:}00\) 分别按当时可用信息生成历史预测；
3. 计算对应预测残差；
4. 当天全部结束后才将该日残差加入历史残差池。

各发布时间的价格残差定义为：

\[
\boxed{
\varepsilon^{p,h}_{k,t}
=
p_{k,t}
-
\widehat p_{k,t\mid h}.
}
\]

---

# 12. 三维联合残差情景

问题四将问题二、问题三中的“负载—光伏联合情景”扩展为：

\[
\boxed{
\text{负载—光伏—电价联合情景}.
}
\]

## 12.1 负载残差

\[
\varepsilon^L_{k,t}
=
L_{k,t}
-
\widehat L_{k,t}.
\]

## 12.2 光伏残差

问题 4-2：

\[
\varepsilon^{pv}_{k,t}
=
P^{pv}_{k,t}
-
\widehat P^{pv}_{k,t}.
\]

问题 4-3 在发布时间 \(h\)：

\[
\varepsilon^{pv,h}_{k,t}
=
P^{pv}_{k,t}
-
\widehat P^{pv}_{k,t,h}.
\]

## 12.3 电价残差

\[
\varepsilon^{p,h}_{k,t}
=
p_{k,t}
-
\widehat p_{k,t\mid h}.
\]

问题 4-2 使用 \(h=0\) 的价格残差。

## 12.4 联合抽样

每次优化只使用最近 60 个已经完成的有效历史日。

有放回抽取：

\[
N=20
\]

个历史日期：

\[
k_1,k_2,\ldots,k_N.
\]

对场景 \(s\)，负载、光伏和价格残差必须来自同一历史日期 \(k_s\)。

由此得到：

\[
\boxed{
L^{(s)}_{d,t}
=
\max
\left[
0,
\widehat L_{d,t}
+
\varepsilon^L_{k_s,t}
\right]
}
\]

\[
\boxed{
P^{pv,(s)}_{d,t,h}
=
\max
\left[
0,
\widehat P^{pv}_{d,t,h}
+
\varepsilon^{pv,h}_{k_s,t}
\right]
}
\]

\[
\boxed{
p^{(s)}_{d,t,h}
=
\max
\left[
0,
\widehat p_{d,t\mid h}
+
\varepsilon^{p,h}_{k_s,t}
\right].
}
\]

整日同日期联合抽样保留：

1. 同一天 144 个时段之间的时间相关性；
2. 负载与光伏预测误差之间的相关性；
3. 电价与供需状态之间的数据相关结构；
4. 极端日期中负载、光伏、价格共同偏离的整体形态。

历史不足 60 天时使用全部已有有效历史。

无有效残差时使用单一确定性预测场景。

# 13. 终端 SOC 价值

问题二和问题三中，固定电价曲线每天重复，因此日末 SOC 价值可由固定日内低价水平定义。问题四中电价逐日变化，终端价值使用历史低价水平的因果滚动估计。

定义历史日 \(k\) 的低价水平为：

\[
q^{low}_k
=
Q_{0.10}
\left(
p_{k,1},\ldots,p_{k,144}
\right),
\]

即该日价格的 10% 分位数。

第 \(d\) 天终端 SOC 单位价值为：

\[
\boxed{
v_{S,d}
=
\frac{
\sum_{j=1}^{7}
\omega_j q^{low}_{d-j}
}{
\eta_c
}.
}
\]

其中：

\[
\eta_c=0.90.
\]

该变量仅使用已完成历史日的价格，不读取当天未来真实价格。

问题 4-2 与问题 4-3 使用同一终端价值定义。

# 54. 问题四的统一模型定位

问题四将前三问中的微网调度问题扩展为三类不确定性的联合决策问题：

\[
\boxed{
\text{负载不确定性}
+
\text{光伏不确定性}
+
\text{电价不确定性}.
}
\]

问题 4-2 描述每天 \(0{:}00\) 一次性制定计划的情形。

问题 4-3 描述多时刻获取新光伏信息、真实价格信息和实测 SOC 后重新优化剩余时段的情形。

两者共享相同的：

- 物理约束；
- 因果信息规则；
- 预测底座；
- 三维联合残差情景；
- CVaR 风险口径；
- 真实回放机制；
- SOC 跨日连续机制。

问题四的结果用于量化：

1. 波动电价对微网全年购电成本的影响；
2. 电价不确定性对紧急购电尾部风险的影响；
3. 储能在动态价格环境中的低价充电与高价放电作用；
4. 日内多次信息更新在负载、光伏和价格同时不确定时的经济价值；
5. 因果价格预测相对于完全价格信息的价值损失。
