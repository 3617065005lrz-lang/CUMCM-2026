只写重点了（个人看法）:
1.Baseline: 不用任何调度，光伏发电作为第一发电路径，只要有光电就先用广电
2.电价与计划购电量：说明模型合理性
3.储电量与放电量：确保储电量在范围内

# 问题一代码说明（第一版）

## 1. 文件用途

问题一代码分为两个阶段：

1. `problem1_data_eda_第一版.py`：完成附件1的数据概览、数据质量检查、预处理和探索性数据分析。
2. `problem1_linear_programming_第一版.py`：建立并求解单日确定性线性规划，输出购电、储能和费用结果。

两个程序都采用144个连续的10分钟时段。输入功率单位为kW，区间电量按照“功率 × 1/6小时”换算为kWh。

## 3. 数据处理与EDA

### 3.1 主要功能

- 检查数据维度、字段类型和取值范围；
- 检查缺失值、重复值、非法时间、负数和异常突变；
- 统一时间顺序，建立144个连续时段编号；
- 将负载和光伏功率换算成每10分钟电量；
- 计算净负荷、电力缺口和光伏富余；

- 计算Pearson和Spearman相关系数；
- 保存绘图缓存，使后续改图不需要重新处理数据。

## 4. 确定性线性规划

### 4.1 模型目标

在满足小区用电需求和储能物理约束的前提下，最小化全天计划购电费用：

```text
全天购电费用 = 各时段电价 × 各时段计划购电量之和
```

### 4.2 决策变量

- 计划购电量；
- 储能充电量；
- 储能放电量；
- 弃光量；
- 时段开始和结束储电量。

### 4.3 主要参数

| 参数        | 数值          |
| --------- | -----------:|
| 时间步长      | 1/6小时       |
| 初始储电量     | 6000 kWh    |
| 最低储电量     | 1200 kWh    |
| 最高储电量     | 10800 kWh   |
| 额定容量      | 12000 kWh   |
| 最大充放电功率   | 5000 kW     |
| 单时段最大充放电量 | 833.333 kWh |
| 充电效率      | 0.90        |
| 放电效率      | 0.90        |

问题一要求0:00和24:00的储电量均为6000 kWh。

### 4.4 主要约束

- 每个时段的电能平衡；
- 储电量递推；
- 储电量上下限；
- 充放电功率限制；
- 弃光量不能超过当期光伏发电量；
- 所有电量变量非负；
- 日初和日末储电量相等。

模型使用SciPy的HiGHS线性规划求解器。

## 5. 结果校验

程序会检查：

- HiGHS是否返回最优状态；
- 最大能量平衡残差；
- 最大储能递推残差；
- 储电量是否越过上下限；
- 日初和日末储电量是否为6000 kWh；
- 充放电量是否超过单时段上限；
- 是否出现负购电量或负弃光量；
- 是否出现同时充放电；
- 购电费用独立复算结果是否与目标函数一致。

求解器返回最优状态并不代表所有输出一定适合直接写入论文，应同时查看`问题一约束校验_第一版.csv`。

## 6. 常见问题

### PermissionError

如果出现无法写入CSV或Excel的错误，通常是目标文件正在被Excel、WPS或其他程序占用。关闭相关文件后重新运行即可。

### 中文显示为方框

程序会自动寻找常见中文字体。若仍然无法显示中文，请在Windows中确认已安装微软雅黑、黑体或宋体。

### plot模式提示缺少缓存

第一次运行必须先使用`all`或相应的`data`、`solve`模式生成缓存。`plot`模式只负责重新绘图，不会重新求解模型。
