# 问题二：微网日前计划与紧急购电两阶段调度模型

## 1. 问题定位

问题二研究负载与光伏发电随日期变化时，微网如何在每天 0:00 制定当天的计划购电策略，并在实际运行过程中利用储能应对光伏预测偏差。当计划购电、实际光伏发电与储能放电仍不足以满足负载时，通过紧急购电补足缺口，紧急购电价格为交易时刻正常电价的 5 倍。

整个问题采用“日前计划—当日执行”的两阶段结构：

\[
\text{历史光伏数据}
\rightarrow
\text{当天光伏预测}
\rightarrow
\text{0:00 制定计划购电}
\rightarrow
\text{当天真实光伏出现}
\rightarrow
\text{重新调度储能}
\rightarrow
\text{必要时紧急购电}
\]

问题一中的储能物理约束继续保留，但不再要求每天 0:00 与 24:00 的储电量相等，而是将真实储电状态连续传递到下一天。

---

## 2. 时间尺度与基本参数

以 10 分钟为一个调度时段，一天划分为

\[
T=144
\]

个时段，时长为

\[
\Delta t=\frac{1}{6}\text{ h}.
\]

功率数据统一乘以 \(\Delta t\) 转换为每个 10 分钟区间的电量。

储能参数为：

| 参数 | 符号 | 数值 |
|---|---:|---:|
| 储能安全下限 | \(S_{\min}\) | 1200 kWh |
| 储能安全上限 | \(S_{\max}\) | 10800 kWh |
| 初始储电量 | \(S_{1,0}\) | 6000 kWh |
| 充电效率 | \(\eta\) | 0.9 |
| 放电效率 | \(\eta\) | 0.9 |
| 最大充电量 | \(C_{\max}\) | \(5000\times\frac16=833.33\) kWh/时段 |
| 最大母线侧放电量 | \(U_{\max}\) | \(5000\times0.9\times\frac16=750\) kWh/时段 |
| 紧急购电价格系数 | \(\lambda_e\) | 5 |

其中，充电量定义为送入储能装置交流侧的电量；放电量定义为储能系统实际送至微网母线侧的电量。因此储能状态递推中，充电按效率折算为实际存入量，放电则需要按照效率反推电池内部消耗量。

---

## 3. 输入—决策—目标—约束

| 要素 | 内容 |
|---|---|
| 输入 | 固定日内电价曲线；附件 2 中每天的小区负载；历史真实光伏发电量；当天实际光伏发电量；储能参数；上一日最终储电量 |
| 预测 | 每天 0:00 利用前 7 天同一时段的真实光伏平均值预测当天光伏 |
| 日前决策 | 144 个 10 分钟计划购电量，以及用于形成计划购电方案的计划充放电轨迹 |
| 执行决策 | 实际充电量、实际放电量、紧急购电量和实际储电状态 |
| 目标 | 在计划阶段降低正常购电费用，在执行阶段尽量减少 5 倍价格的紧急购电 |
| 核心约束 | 逐时段供电充足、储能状态递推、储电量安全区间、充放电功率限制、购电非负、跨日 SOC 连续 |

---

# 4. 光伏预测模型

## 4.1 预测原则

每天 0:00 制定计划时，当天真实光伏发电尚未发生，因此不能直接把当天真实光伏作为全天计划的输入。

利用光伏具有明显日内周期和短期连续性的特点，用最近一周历史数据估计当天的日内光伏曲线。

设 \(P^{pv}_{d,t}\) 为第 \(d\) 天第 \(t\) 个时段的真实光伏电量，则对于历史数据完整的日期，预测值取为：

\[
\boxed{
\hat P^{pv}_{d,t}
=
\frac{1}{7}
\sum_{k=1}^{7}
P^{pv}_{d-k,t}
}
\]

即：

> 第 \(d\) 天某一 10 分钟时段的预测光伏，取前 7 天相同时段真实光伏电量的算术平均。

这种方法保持了每天 144 个时段完整的日内形态，同时能够随季节变化逐渐调整光伏水平。

## 4.2 年初历史不足的处理

2025 年最初 7 天无法获得完整的一周历史数据，因此暂时采用附件 1 给出的单日光伏预测曲线作为预测输入。

从第 8 天开始，统一采用前 7 天真实光伏逐时段平均值。

最终结果从 2 月 1 日开始输出，因此在正式输出期开始之前已经具有充足的历史观测。

# 5. 第一阶段：0:00 日前计划购电模型

## 5.1 第一阶段输入

对于第 \(d\) 天，在 0:00 进行计划时使用：

\[
p_t,\qquad
L_{d,t},\qquad
\hat P^{pv}_{d,t},\qquad
S_{d,0}.
\]

其中：

- \(p_t\)：第 \(t\) 个时段正常购电价格；
- \(L_{d,t}\)：当天第 \(t\) 个时段负载电量；
- \(\hat P^{pv}_{d,t}\)：当天光伏预测电量；
- \(S_{d,0}\)：当天 0:00 的实际储电量。

在该建模思路中，负载作为当天计划阶段的已知输入，预测误差主要体现在光伏发电侧。

---

## 5.2 决策变量

对 \(t=1,\ldots,144\)，定义：

\[
x_{d,t}\ge 0
\]

为当天 0:00 锁定的计划购电量；

\[
c^{p}_{d,t}\ge0
\]

为计划阶段的充电量；

\[
u^{p}_{d,t}\ge0
\]

为计划阶段的放电量；

\[
S^{p}_{d,t}
\]

为计划阶段对应的储电状态。

其中 \(c^{p}_{d,t}\)、\(u^{p}_{d,t}\) 和 \(S^{p}_{d,t}\) 的作用是帮助确定合理的计划购电量，真正执行时储能可以根据实际光伏重新调度。

---

## 5.3 目标函数

第一阶段只考虑正常计划购电费用：

\[
\boxed{
\min
\sum_{t=1}^{144}
p_t x_{d,t}
}
\]

为避免存在相同购电费用但充放电轨迹不同的退化解，可以加入极小的充放电通量惩罚：

\[
\min
\left[
\sum_{t=1}^{144}p_tx_{d,t}
+
\varepsilon
\sum_{t=1}^{144}
\left(c^{p}_{d,t}+u^{p}_{d,t}\right)
\right],
\qquad
\varepsilon\rightarrow0^+.
\]

该项只用于在等价最优解之间选择更简洁的储能轨迹，不改变购电费用最小这一主目标。

---

## 5.4 计划阶段供电约束

每个 10 分钟时段要求预测条件下的可用电量不少于负载及充电需求：

\[
\boxed{
x_{d,t}
+
\hat P^{pv}_{d,t}
+
u^{p}_{d,t}
\ge
L_{d,t}
+
c^{p}_{d,t}
}
\]

左侧为计划阶段可获得的电能：

- 正常计划购电；
- 预测光伏发电；
- 储能放电。

右侧为电能去向：

- 小区负载；
- 储能充电。

采用不等式意味着允许出现无法进一步利用的富余电量，该部分可理解为隐含弃光或其他未利用电量，不允许通过负购电向外网售电。

---

## 5.5 计划阶段储能递推

储能状态满足：

\[
\boxed{
S^{p}_{d,t}
=
S^{p}_{d,t-1}
+
\eta c^{p}_{d,t}
-
\frac{u^{p}_{d,t}}{\eta}
}
\]

其中：

\[
S^{p}_{d,0}=S_{d,0}.
\]

充入 \(c^{p}_{d,t}\) kWh 时，真正增加到储能内部的电量为

\[
\eta c^{p}_{d,t},
\]

而向微网实际释放 \(u^{p}_{d,t}\) kWh 时，需要从储能内部消耗

\[
\frac{u^{p}_{d,t}}{\eta}.
\]

---

## 5.6 计划阶段边界约束

储电量安全约束：

\[
1200
\le
S^{p}_{d,t}
\le
10800.
\]

充电功率约束：

\[
0
\le
c^{p}_{d,t}
\le
833.33.
\]

放电功率约束：

\[
0
\le
u^{p}_{d,t}
\le
750.
\]

计划购电非负：

\[
x_{d,t}\ge0.
\]

求解该线性规划后得到的

\[
x_{d,1},x_{d,2},\ldots,x_{d,144}
\]

就是第 \(d\) 天 0:00 制定并锁定的全天计划购电策略。

---

# 6. 第二阶段：真实运行与紧急购电模型

## 6.1 两阶段之间的关系

全天计划购电量

\[
x_{d,t}
\]

一旦在 0:00 确定，当天执行过程中不再改变。

随着时间推进，真实光伏

\[
P^{pv}_{d,t}
\]

逐渐出现，并可能与日前预测

\[
\hat P^{pv}_{d,t}
\]

存在偏差。

此时不重新制定计划购电量，而是重新安排储能的真实充放电。如果仍然存在供电缺口，则使用紧急购电补足。

---

## 6.2 执行阶段决策变量

定义：

\[
c_{d,t}\ge0
\]

为实际充电量；

\[
u_{d,t}\ge0
\]

为实际放电量；

\[
e_{d,t}\ge0
\]

为紧急购电量；

\[
S_{d,t}
\]

为实际储电量。

---

## 6.3 执行阶段目标函数

由于正常计划购电 \(x_{d,t}\) 已经在 0:00 锁定，其费用已经确定。在执行阶段只需要寻找使紧急购电费用尽可能小的储能调度方案：

\[
\boxed{
\min
\sum_{t=1}^{144}
5p_t e_{d,t}
}
\]

同样可以加入极小的充放电通量惩罚：

\[
\min
\left[
\sum_{t=1}^{144}5p_t e_{d,t}
+
\varepsilon
\sum_{t=1}^{144}
(c_{d,t}+u_{d,t})
\right].
\]

---

## 6.4 实际供电约束

当天真实运行时，每个时段满足：

\[
\boxed{
x_{d,t}
+
e_{d,t}
+
P^{pv}_{d,t}
+
u_{d,t}
\ge
L_{d,t}
+
c_{d,t}
}
\]

其中：

- \(x_{d,t}\)：已经锁定的正常计划购电；
- \(e_{d,t}\)：临时增加的紧急购电；
- \(P^{pv}_{d,t}\)：当天真实光伏；
- \(u_{d,t}\)：实际储能放电；
- \(L_{d,t}\)：真实负载；
- \(c_{d,t}\)：实际储能充电。

如果计划购电、真实光伏和储能放电已经足够满足负载，则最优情况下：

\[
e_{d,t}=0.
\]

如果仍然存在缺口，则：

\[
e_{d,t}>0,
\]

并按正常电价的 5 倍结算。

---

## 6.5 实际储能递推

真实储电状态满足：

\[
\boxed{
S_{d,t}
=
S_{d,t-1}
+
\eta c_{d,t}
-
\frac{u_{d,t}}{\eta}
}
\]

并满足：

\[
1200
\le
S_{d,t}
\le
10800,
\]

\[
0
\le
c_{d,t}
\le
833.33,
\]

\[
0
\le
u_{d,t}
\le
750.
\]

紧急购电量满足：

\[
e_{d,t}\ge0.
\]

---

# 7. 跨日储能状态连续

问题二不再要求每天 24:00 的储电量回到当天 0:00 的水平。

全年只给定一个初始状态：

\[
\boxed{
S_{2025/1/1,\,0}=6000\text{ kWh}
}
\]

此后按照真实执行阶段得到的储电量逐日传递：

\[
\boxed{
S_{d+1,0}
=
S_{d,144}
}
\]

因此：

> 今天真实运行结束时电池剩多少电，明天就从多少电开始运行。

这使全年储能轨迹成为一条连续状态路径，而不是每天重新初始化。

---

# 8. 全年滚动求解流程

第二问按日期顺序从 2025 年 1 月 1 日连续推进。

对于每一天 \(d\)，执行以下流程：

### 步骤 1：确定当天初始储电量

首日：

\[
S_{1,0}=6000.
\]

以后：

\[
S_{d,0}=S_{d-1,144}.
\]

### 步骤 2：生成当天光伏预测

若已有至少 7 天历史：

\[
\hat P^{pv}_{d,t}
=
\frac{1}{7}
\sum_{k=1}^{7}
P^{pv}_{d-k,t}.
\]

否则使用初始光伏预测曲线。

### 步骤 3：求解日前计划模型

输入：

\[
p_t,\quad
L_{d,t},\quad
\hat P^{pv}_{d,t},\quad
S_{d,0}.
\]

得到：

\[
x_{d,t}.
\]

### 步骤 4：锁定全天计划购电

当天 144 个

\[
x_{d,t}
\]

保持不变。

### 步骤 5：代入当天真实光伏

使用：

\[
P^{pv}_{d,t}
\]

进入真实执行模型。

### 步骤 6：重新安排实际储能

优化：

\[
c_{d,t},\quad
u_{d,t}.
\]

优先利用储能缓冲预测偏差。

### 步骤 7：补充紧急购电

若仍有电力缺口，则产生：

\[
e_{d,t}>0.
\]

### 步骤 8：更新实际储电量

得到当天 24:00：

\[
S_{d,144}.
\]

将其作为下一天 0:00 的初始状态。

然后继续下一日，直至 2025 年 12 月 31 日。

---

# 9. 费用核算

虽然两个阶段分别求解，但最终一天的实际购电总费用由两部分组成。

## 9.1 正常计划购电费

\[
C_d^{plan}
=
\sum_{t=1}^{144}
p_t x_{d,t}.
\]

## 9.2 紧急购电费

\[
C_d^{emg}
=
\sum_{t=1}^{144}
5p_t e_{d,t}.
\]

## 9.3 当日总费用

\[
\boxed{
C_d
=
C_d^{plan}
+
C_d^{emg}
}
\]

全年总费用为：

\[
\boxed{
C_{\text{year}}
=
\sum_d C_d
}
\]

因此，模型的经济逻辑可以概括为：

> 日前阶段利用光伏预测尽量安排低成本的正常购电；实际阶段利用储能吸收预测误差，只在储能无法完全补偿供电缺口时使用高成本紧急购电。

---

# 10. 模型性质

两个阶段均满足：

- 目标函数为线性函数；
- 供电约束为线性约束；
- SOC 状态方程为线性等式；
- 储能容量和功率约束均为线性边界。

因此两个阶段都属于：

\[
\boxed{\text{线性规划（Linear Programming，LP）}}
\]

每天需要连续求解两个规模较小的线性规划：

\[
\text{日前计划 LP}
\rightarrow
\text{实际执行 LP}.
\]

全年再按照储能实际状态逐日串联。

---

# 11. 建模逻辑总结

问题二可以归纳为三层结构：

## 第一层：短期光伏预测

\[
\text{前 7 天真实光伏}
\rightarrow
\text{当天 144 点光伏预测}
\]

解决“0:00 时并不知道当天真实光伏”的信息约束。

## 第二层：日前计划优化

\[
(\text{电价},\text{负载},\text{预测光伏},\text{当前 SOC})
\rightarrow
\text{计划购电量}
\]

目标是尽量降低正常计划购电成本。

## 第三层：实际运行补救

\[
(\text{已锁定计划购电},\text{真实光伏},\text{当前 SOC})
\rightarrow
\text{实际充放电}
\rightarrow
\text{紧急购电}
\]

目标是通过储能尽量吸收预测误差，降低 5 倍价格紧急购电的使用。

最终形成：

\[
\boxed{
\text{滚动光伏预测}
+
\text{日前计划 LP}
+
\text{实际执行 LP}
+
\text{紧急购电补救}
+
\text{SOC 跨日连续}
}
\]

这一结构既保留了问题一的储能物理模型，又将光伏预测误差和高价紧急购电机制纳入全年连续调度过程。
