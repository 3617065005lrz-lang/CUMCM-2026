# CUMCM 2026 微网电力调度建模

本仓库整理了 2026 年全国大学生数学建模竞赛微网电力调度课题的建模思路、Python 程序、结果表与论文插图。内容覆盖确定性线性规划、滚动预测、两阶段随机规划、CVaR 风险控制与波动电价分析。

> 仓库主要用于复现建模过程和归档竞赛结果。原始赛题附件未提交到仓库，运行代码前请自行准备对应的 `附件1.xlsx` 至 `附件4.xlsx`。

## 主要方法

1. **问题一：确定性调度**
   使用 SciPy HiGHS 求解单日线性规划，在电能平衡、储能容量、充放电功率和日初日末 SOC 等约束下最小化购电费用。
2. **问题二：不确定性调度**
   基于因果滚动预测和联合残差场景建立两阶段随机线性规划，并比较规则基线、确定性规划和随机规划。
3. **问题三：滚动修正**
   利用日内多个预报发布时间逐步更新光伏预测和购电计划，分析预测信息的价值。
4. **问题四：波动电价与风险控制**
   将实时电价及 CVaR 尾部风险纳入统一模型，比较固定电价与波动电价环境下的调度表现。

## 快速开始

### 环境

- Python 3.11+
- NumPy
- pandas
- SciPy
- Matplotlib
- seaborn
- openpyxl

```bash
python -m pip install -r requirements.txt
```

### 示例

问题一：

```bash
cd Question_1
python problem1_linear_programming_第一版.py --input "附件1.xlsx" --mode all
```

问题二（推荐第二版）：

```bash
cd Question_2/code
python problem2_stochastic_programming_第二版.py \
  --attachment1 "附件1.xlsx" \
  --attachment2 "附件2.xlsx" \
  --mode all
```

各问题的参数、输入格式、输出表和校验方式见对应目录中的 README 或模型说明文档。

## 结果文件约定

- `figures/`：论文插图和流程图；
- `数据表/`：模型输出、质量检查、预测指标和约束校验；
- `result*.xlsx`：便于论文写作与复核的汇总工作簿；
- 文件名中的“第一版”“第二版”用于保留竞赛期间的迭代记录。

大型 CSV/XLSX 文件是已生成结果，不是运行代码的必需依赖。重新运行前建议另设输出目录，避免覆盖已归档结果。

## 复现说明

- 代码默认使用中文文件名及 Windows 环境中常见的中文字体；
- 问题二、三、四的完整年度求解耗时较长；
- 使用结果前应优先检查各目录中的求解日志和约束校验表；
- `plot` 模式通常依赖先前生成的绘图缓存，缺少缓存时应先运行 `solve` 或 `all`。
