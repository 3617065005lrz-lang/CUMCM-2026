# 问题一数据处理与探索性数据分析第一版

## 1 项目说明

本代码用于完成 2026 年高教社杯全国大学生数学建模竞赛 C 题问题一的数据准备工作，包括：

- 读取附件 1 的全部数据；
- 给出数据规模、字段类型、取值范围等数据概览；
- 检查缺失值、异常值、重复值和时间一致性；
- 按业务规则优先的原则完成数据预处理；
- 保留预处理前后的对比结果；
- 对电价、小区负载、光伏预测功率和净负荷进行探索性数据分析；
- 保存绘图缓存，支持后续单独修改图片而不重新执行数据处理。

本代码只负责问题一的数据处理和探索性数据分析，不求解购电与储能优化模型，也不会生成 `result1.xlsx`。

## 4 运行方法

### 4.1 生成全部数据表和图片

```powershell
py -3.11 problem1_data_eda_第一版.py --input "附件1.xlsx" --mode all
```

`all` 模式会依次执行数据读取、质量检查、预处理、统计分析、缓存保存和图片生成。

### 4.2 只生成数据表和绘图缓存

```powershell
py -3.11 problem1_data_eda_第一版.py --input "附件1.xlsx" --mode data
```

适合第一次检查数据，或者只需要统计表、不需要立即出图的情况。

### 4.3 只读取缓存重新绘图

```powershell
py -3.11 problem1_data_eda_第一版.py --output-dir "问题一数据处理输出_第一版" --mode plot
```

`plot` 模式不会重新读取附件 1，也不会重新执行数据质量检查，只使用已有的绘图缓存生成图片。修改绘图代码后，优先使用该模式，可以节省时间。

如果绘图缓存不存在，程序会提示先运行 `data` 或 `all` 模式。

### 4.4 指定工作表和输出位置

```powershell
py -3.11 problem1_data_eda_第一版.py --input "附件1.xlsx" --sheet "Sheet1" --output-dir "问题一数据处理输出_第一版" --mode all
```

未填写 `--sheet` 时，程序默认读取附件 1 的第一个工作表。

## 5 可调整参数

| 参数 | 默认值 | 作用 |
|---|---:|---|
| `--input` | `附件1.xlsx` | 输入数据路径 |
| `--output-dir` | `问题一数据处理输出_第一版` | 输出文件夹路径 |
| `--sheet` | 第一个工作表 | 指定读取的工作表 |

例如，将图片分辨率设为 400：

```powershell
py -3.11 problem1_data_eda_第一版.py --input "附件1.xlsx" --mode all --dpi 400
```

## 6 数据处理口径

### 6.1 时间口径

附件 1 每一行代表一个 10 分钟区间，时间列按区间右端点解释：

- `0:10` 对应 `0:00-0:10`；
- `0:20` 对应 `0:10-0:20`；
- `0:00+1` 对应 `23:50-24:00`。

程序将 Excel 时间对象和文本时间统一转换为区间终点分钟，并检查是否完整覆盖一天的 144 个 10 分钟区间。

### 6.2 单位换算

附件中的小区负载和光伏预测数据单位为 kW。问题一的能量平衡和购电量单位为 kWh，因此程序按下式换算：

\[
\text{每 10 分钟电量}=\text{功率}\times\frac{1}{6}
\]

程序同时计算：

\[
\text{净负荷功率}=\text{小区负载功率}-\text{光伏预测功率}
\]

\[
\text{净负荷电量}=\text{净负荷功率}\times\frac{1}{6}
\]

净负荷为正表示当前存在电力缺口；净负荷为负表示当前存在光伏富余。这里尚未考虑储能充放电和外网购电策略。

### 6.3 异常处理原则

代码遵循“业务规则优先、异常只标记不擅自删除”的原则：

- 不自动删除异常记录；
- 不自动对极端值进行缩尾；
- 不自动填补无法解析的数据；
- 夜间光伏零值视为正常现象，不作为缺失值；
- 6:00 至 18:00 出现的光伏零值只提示复核，不自动插值；
- IQR、稳健 Z 分数和相邻时段突变只用于发现可疑记录；
- 负载和光伏功率为负视为违反当前业务规则；
- 负电价只标记复核，因为部分电力市场可能存在负电价，不能仅凭统计规则删除。

如果同一条记录同时触发多项规则，异常记录表中可能出现多条对应记录。

## 8 数据表说明

### 8.1 原始数据副本

保存附件 1 的原始四个字段，并增加原始 Excel 行号。该文件用于追溯数据，不进行数值修改。

### 8.2 清洗后数据

这是后续建模最主要的输入文件，包含：

- 原始 Excel 行号；
- 时间段编号；
- 原始时间；
- 区间终点分钟；
- 标准时间段；
- 电价；
- 小区负载功率和电量；
- 光伏预测功率和电量；
- 净负荷功率和电量；
- 电力缺口电量；
- 光伏富余电量；
- 处理状态。

处理状态分为：

- `保留`：未触发检查规则；
- `存在提示，保留待复核`：触发统计异常或提示性规则；
- `存在数据问题，保留待处理`：存在缺失、非法数值、重复时间或违反业务规则等问题。

### 8.3 数据集概览

说明工作表、原始行列数、预期时间段数、可解析时间数、时间粒度及覆盖范围，用于快速确认附件结构是否符合问题一要求。

### 8.4 字段概览

逐字段给出：

- 原始值类型构成；
- 清洗后类型；
- 记录数和非空数；
- 缺失数和唯一值数；
- 最小值和最大值；
- 单位及字段含义。

### 8.5 数据质量检查

汇总结构完整性、字段完整性、缺失值、重复值、时间一致性、数值类型和业务规则检查结果。

“通过”表示该项未发现问题；“需处理”表示存在明确的数据问题；“仅标记”表示统计方法发现了可疑记录，但代码没有修改原始值。

### 8.6 异常记录

逐条列出触发检查规则的记录，包括原始 Excel 行号、时间段、字段、异常类型、原始值、判定依据、处理方式和严重程度。

该表的作用是帮助人工复核，不代表其中所有记录都必须删除。

### 8.7 预处理前后对比

比较预处理前后的记录数、字段数、缺失情况、重复情况、时间解析、单位和异常处理状态，证明数据处理过程可追溯。

如果原始数据质量较好，预处理前后记录数保持不变是正常结果，不需要为了体现“清洗效果”而强行删数据。

### 8.8 描述统计

对电价、小区负载、光伏预测功率和净负荷给出非空数、均值、标准差、最小值、最大值、中位数、分位数和零值数。

### 8.9 相关系数

- 皮尔逊相关系数用于观察变量间的线性关系；
- 斯皮尔曼相关系数用于观察变量间的单调关系，对极端值相对不敏感。

净负荷由负载和光伏计算得到，因此净负荷与二者之间的相关性带有公式上的必然关系，不能直接解释为新的因果结论。

## 10 推荐查看顺序

第一次运行后，建议按以下顺序检查：

1. 查看 `数据集概览_第一版.csv`，确认数据规模和时间覆盖；
2. 查看 `数据质量检查_第一版.csv`，确认是否存在必须处理的问题；
3. 查看 `异常记录_第一版.csv`，逐条判断异常是否真实；
4. 查看 `预处理前后对比_第一版.csv`，确认没有无依据删除数据；
5. 查看 `清洗后数据_第一版.csv`，核对时间映射和单位换算；
6. 查看描述统计和相关系数表；
7. 最后检查六张图片，并挑选真正能支撑论文分析的图。

## 11 与后续建模的关系

问题一后续优化模型应优先读取 `清洗后数据_第一版.csv`，复用其中的标准时间段、电价、负载电量、光伏电量和净负荷电量。

后续建模仍需单独加入：

- 外网计划购电量；
- 储能充电量和放电量；
- 储电量状态递推；
- 充放电效率；
- 储能容量和功率限制；
- 0:00 与 24:00 储电量相同；
- 弃光量；
- 购电费用目标函数；
- 能量守恒、储能边界和费用复算。

本阶段生成的“电力缺口”和“光伏富余”均为未考虑储能调度的基础指标，不能直接当作问题一的最终购电量或弃光量。

## 12 常见问题

### 12.1 提示找不到附件1

确认 `附件1.xlsx` 与代码位于同一文件夹，或者使用完整路径：

```powershell
py -3.11 problem1_data_eda_第一版.py --input "D:\比赛资料\附件1.xlsx" --mode all
```

### 12.2 提示缺少模块

使用运行代码的同一个 Python 3.11 环境安装依赖：

```powershell
py -3.11 -m pip install pandas numpy matplotlib seaborn openpyxl
```

不要使用一个 Python 环境安装依赖，再用另一个 Python 环境运行代码。

### 12.3 图片中文显示为方框

代码会优先尝试微软雅黑、黑体、思源黑体等中文字体。Windows 通常可以直接使用微软雅黑。如果仍显示方框，应先确认系统已安装可用中文字体，再重新运行 `plot` 模式。

### 12.4 修改图片后是否需要重跑数据处理

不需要。只要 `绘图缓存_第一版` 中的三个缓存文件仍然存在，运行以下命令即可：

```powershell
py -3.11 problem1_data_eda_第一版.py --output-dir "问题一数据处理输出_第一版" --mode plot
```

### 12.5 异常记录是否需要全部删除

不需要。统计异常只是复核线索。只有确认记录违反题目约束、录入规则或时间结构后，才能决定是否修正；任何修正都应保留依据和处理前后对比。

## 13 使用边界

- 本代码不包含购电策略优化；
- 本代码不生成问题一最终答案；
- 本代码不直接填充官方结果模板；
- 本代码不自动删除或替换异常值；
- 探索性分析只用于发现数据规律和支持后续建模，不能代替优化模型及其约束检验。
